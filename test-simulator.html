🧪 סימולטור אימות עבור Gemini MCP Bridge

דף זה מאפשר לבדוק את אופן זיהוי הפקודות והתקשורת של התוסף עם Supabase.

שלום! אני ג'מיני. כיצד אוכל לעזור לך עם מסד הנתונים Supabase שלך היום?
💡 איך להפעיל את התוסף בכרום:
  1. פתח את chrome://extensions בדפדפן.
  2. הפעל את Developer mode (מצב מפתח) בפינה העליונה.
  3. לחץ על Load unpacked ובחר את התיקייה gemini MCP/extension.
  4. היכנס ל-https://gemini.google.com ותראה את הכפתור הכחול הצף ⚡ Supabase MCP!
