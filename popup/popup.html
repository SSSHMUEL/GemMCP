💡

מה זה GemMCP ואיך משתמשים?

🚀 מה התוסף הזה עושה?

GemMCP מחבר את ממשק Gemini Web הרגיל בדפדפן לעולם החיצון (Model Context Protocol). הוא מעניק לג'מיני "ידיים ורגליים" לבצע פעולות אמיתיות:

  • 💻 Windows MCP – קריאה וכתיבה של קבצים, הרצת פקודות טרמינל (PowerShell/CMD), והפעלת תוכנות במחשב.
  • ⚡ Supabase – תשאול וניהול טבלאות SQL ומסדי נתונים ישירות מהשיחה.
  • Notion – קריאה וכתיבה של דפים, משימות ומאגרי מידע ב-Notion.
  • GitHub – חיפוש מאגרי קוד, קריאת קבצים, Issues ו-Pull Requests.
  • 🌐 Web Scraper – גלישה וקריאת תוכן מאתרים חיים בזמן אמת.
  • 🧩 שרתי MCP מותאמים – הוספת כל שרת MCP חיצוני (Local או SSE / Remote).
  • 🔑 שרת ומפתח API – חיבור תוכנות חיצוניות (Cursor, Python, Cline) לחשבונות ה-AI בדפדפן בחינם וללא עלות Tokens.
🎯 איך משתמשים בזה? (3 צעדים פשוטים)
1
חיבור והפעלת השירותים הרצויים:

בחלון זה, לחץ על השירות שברצונך לחבר (התחברות בקליק או הזנת API Key) והפעל את המתג שלו למצב פעיל (ON). לחץ על "שמור את כל ההגדרות".

2
גלישה לאתר Gemini:

פתח את gemini.google.com ↗. תראה בפינת המסך את הווידג'ט הצף של GemMCP.

3
הפעלת הפרומפט ודיבור חופשי:

לחץ על כפתור "הפעל GemMCP" בווידג'ט להזרקת ההנחיות (או תייג @GemMCP). כעת בקש מג'מיני כל משימה (למשל: "צור קובץ index.html על שולחן העבודה" או "בדוק אילו טבלאות יש לי ב-Supabase").

🛡️ אישור אוטומטי (Auto Run) ובקרת אבטחה

בברירת מחדל, מצב Auto Run מופעל ומבצע פעולות מיד. במידה ותרצה לאשר כל פקודה/קובץ ידנית לפני ביצועה, כבה את מתג ה-Auto Run בווידג'ט הצף.

🤖

מדריך חיבור ל-OpenAI API המקומי

💡 מה זה ואיך זה עובד?

שרת ה-Bridge מדמה API מלא של OpenAI ומעביר את הפניות לחשבון הבינה המחובר בדפדפן שלך (Gemini / Claude / ChatGPT) – בחינם וללא עלות טוקנים.

🎯 ניתוב אוטומטי לפי שדה model

בשדה המודל בתוכנה שלך, הגדר לאיזו בינה השאילתה תנותב:

  • "model": "gemini" ➔ מריץ באתר Gemini
  • "model": "claude" ➔ מריץ באתר Claude
  • "model": "chatgpt" ➔ מריץ באתר ChatGPT
🛡️ כרטיסיית רקע ייעודית: התוסף פותח כרטיסייה נפרדת עבור ה-API מבלי להפריע לכרטיסיות שאתה עובד בהן כרגע!
🌐 3 אפשרויות חיבור (Base URLs)
  • באותו המחשב: http://127.0.0.1:3000/v1
  • ברשת ה-Wi-Fi הביתית: http://<IP_של_המחשב>:3000/v1
  • מכל מקום בעולם (HTTPS): הפעל מנהרת Cloudflare לקבלת קישור מאובטח.
📦 מבנה השאילתה (JSON Body)
POST /v1/chat/completions 
{
  "model": "gemini",
  "messages": [
    {
      "role": "user",
      "content": "שלום, תסביר לי בכמה מילים מה זה MCP"
    }
  ],
  "stream": false
}
🐍 דוגמת קוד בפייתון (OpenAI SDK)
python (openai) 
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:3000/v1",
    api_key="YOUR_API_KEY_FROM_POPUP"
)

response = client.chat.completions.create(
    model="gemini", # או "claude" / "chatgpt"
    messages=[
        {"role": "user", "content": "מה השעה ואיזה יום היום?"}
    ]
)

print(response.choices[0].message.content)
